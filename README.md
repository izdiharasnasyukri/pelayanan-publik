# pelayanan-publik

Aplikasi web berbasis sistem informasi geografis (GIS) untuk layanan publik, pelaporan warga, serta pemetaan fasilitas umum dan infrastruktur masyarakat di Kabupaten Pandeglang.

## Tech Stack
- *Frontend:* HTML5, CSS3, JavaScript (ES6+), Bootstrap 5
- *Maps API:* Leaflet.js / OpenStreetMap
- *Database & Backend:* Supabase (PostgreSQL / MySQL compatible)
-**Frame work**
Bootstrap 5.3
